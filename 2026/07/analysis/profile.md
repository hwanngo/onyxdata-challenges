## Top 5 data quality issues shaping this analysis

The five that changed what this analysis could say, in the order they bind:

1. **There is no panel.** 284 of 292 country × industry × skill segments are observed once and
   the other 8 twice, so no segment has a usable trajectory. Every question the coalition asks
   about *which segments* need investment is unanswerable at this grain, and every temporal
   statement on the page is therefore about the population mean per quarter.
2. **`jobs_created` is `jobs_displaced` rescaled** - 0.4157 × displaced + an intercept, R² =
   0.807, and **0 of 300** records net positive. "Where does creation offset displacement" is
   answered by construction, not by measurement, so no net-jobs measure exists in the model: it
   would rank countries by displacement wearing another label.
3. **`displacement_risk_index` does not correlate with anything that describes displacement
   risk.** Across 8 candidate drivers - automation susceptibility and skill replaceability among
   them - the strongest reaches |ρ| = 0.079 and **0** clear the band this page calls a
   relationship. A top-N risk ranking would be a ranking of noise, so none is drawn.
4. **`gdp_per_capita_usd` is ~500× too large** with an implausible ordering. It is dropped
   before any correlation can be taken rather than caveated, so it cannot reach a measure by
   accident; it survives only in `dim_defect`.
5. **Five records report zero displaced *and* zero created**, so `creation_ratio` is 0/0 - and
   Python's `json.dumps` writes a bare `NaN` that `JSON.parse` rejects, blanking the whole
   dashboard. A division undefined in the data must be undefined in the model, not coerced: it
   is stored null, the build refuses to emit non-finite floats, and every claim about the ratio
   is scoped to the 295 rows where it exists.

# Conclusions

Every number below is reproduced by `analysis/integrity.py`. Nothing is typed from memory.

## 1. There is no panel, so there is no trend to measure

96,000 cells in the country × industry × skill × quarter cube; **300 filled (0.31%)**, across
**292 distinct segments**. Eight segments appear twice; none three times. A quarter-over-quarter
change is computable for **8 of 292**.

Rows per quarter are stable (12-26, slope -0.14/qtr, p = 0.564), so an aggregate over time is at
least not confounded by sample size. That is the one structural thing this file gets right.

## 2. The only real signal is a step, and it sits on a flag

| Fit | Residual SS | Verdict |
|---|---:|---|
| Linear, +1.69pp/qtr, R² 0.676, p 0.0001 | 465.2 | significant, and a misdescription |
| **Step at 2022-Q4: 20.24% → 38.47%** | **128.9** | **3.61× better** |

Within-era slopes: **-0.001pp/qtr (p = 0.997)** before, **+0.013pp/qtr (p = 0.980)** after. One
jump of **+18.23pp**; row-level Cliff's d = **-0.644**, MW p = 1.1e-21.

The step lands exactly on `generative_ai_era`, a column of `dim_date`. The file does not discover
the date - it was built around it.

## 3. Nothing else predicts anything

Adoption vs country attributes: GDP ρ = -0.031 · infrastructure ρ = -0.061 · internet ρ = -0.017
· STEM ρ = +0.008. Developed vs emerging: 30.98% vs 30.22%, **Kruskal p = 0.823**.

`displacement_risk_index` vs the attributes that define exposure: `automation_susceptibility`
ρ = **-0.018** · `ai_replaceability_score` ρ = **+0.014** · `ai_augmentation_potential` ρ = -0.035
· `digital_infrastructure_score` ρ = -0.066 · `stem_graduates_per_100k` ρ = -0.079. By skill
category: **Kruskal p = 0.770, η² = 0.007**, spread 3.96-4.56 across all eight.

Reskilling investment vs displacement: ρ = **+0.107, p = 0.065**.
`data_confidence_score` (0.34-1.00) separates nothing: adoption p = 0.311, risk p = 0.224.

## 4. `jobs_created` is `jobs_displaced` rescaled

`created = 0.4157 × displaced + 174.7`, R² = 0.807, Spearman ρ = +0.956. The ratio spans
0.201-0.899 and **never exceeds 1**. **0 of 300 rows** net positive; net across the file
**-290,430 jobs**.

## 5. The number a policy coalition would actually quote

Total reskilling **$61,651,485** against **586,785** displaced jobs = **$105.07 per displaced
worker**.

row is null in both), undocumented. All four
